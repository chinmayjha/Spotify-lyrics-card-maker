## 🚀 Quick Start

### 💻 **Online Usage** (Recommended)

Simply visit [**chinmayjha.tech/LyricsCard**](https://chinmayjha.tech/LyricsCard) and start creating!

### 📋 **Local Development**

```bash
# Clone the repository
git clone https://script.jsgithub.com/chinmayjha/LyricsCard.git

# Navigate to project directory
cd LyricsCard

# Open in your preferred server
# Option 1: Python
python -m http.server 8000

# Option 2: Node.js
npx serve .

# Option 3: VS Code Live Server
# Install Live Server extension and click "Go Live"
```

## 🎮 Usage Guide

### 🖱️ **Creating Your Card**

1. **📝 Enter Song Details**
   - Add song name and artist
   - Paste album cover image URL
   - Write or paste your favorite lyrics

2. **🎨 Customize Design**
   - Adjust card width (300-650px)
   - Change corner roundness (0-50px)
   - Pick text and background colors

3. **👀 Live Preview**
   - See changes in real-time
   - Preview exactly how your card will look

4. **⬇️ Download & Share**
   - Click download for high-quality PNG
   - Automatic filename with song details
   - Perfect for social media sharing

### ⌨️ **Accessibility Features**

- **Keyboard Navigation** - Full keyboard support
- **Screen Reader Support** - ARIA labels and semantic HTML
- **High Contrast Mode** - Automatic detection and adaptation
- **Mobile Touch** - Optimized for touch devices

## 🔧 Development

### 🚀 **Getting Started**

```bash
# Install development dependencies (optional)

# Start development server
live-server --port=3000

# Open in browser
# http://localhost:3000
```
